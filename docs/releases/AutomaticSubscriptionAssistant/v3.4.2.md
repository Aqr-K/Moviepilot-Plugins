# 自动订阅助手 v3.4.2 发布说明

本版本仅面向 MoviePilot v3，以下变化以 3.4.1 为基线。

## 市场更新日志

增加：全局设置新增还原全部默认配置的一次性维护入口，确认后自动备份并还原，保留历史、黑名单及已有订阅；异常来源支持单独还原。优化：各来源规则数值采用宽范围配置，获取数量为 0 时暂停规则，实际获取量按来源接口处理。修复：旧版奈飞等来源因获取数量超限导致配置迁移失败的问题；配置异常阻断来源列表渲染及全部来源运行的问题，异常来源保留原配置并单独暂停，其他来源可正常运行和保存。

## 配置升级与来源恢复

旧版奈飞配置中的每榜 20、50 或更大的获取数量不再被规则表单上限拒绝。各来源的条数、年份、评分和人次取消固定上限，继续检查非负、有限数及整数类型；获取数量为 0 时暂停该规则。接口自身的容量仍由请求层处理，实际返回数量以来源为准。

配置升级按来源分别处理。单个来源无法迁移或规则校验失败时，保留原配置及备份，仅暂停该来源，其他来源继续运行。保存其他来源时不会将异常来源的显示默认值覆盖到存储中。配置读取失败也不再阻止来源导航和全局维护入口显示。备份或持久化失败仍会停止自动任务。

## 一次性维护

在「订阅配置 → 全局设置 → 一次性维护」中点击「还原全部默认配置」，确认后先备份完整当前配置，再立即恢复默认值。插件和全部来源会关闭，未保存的草稿会被放弃；历史、黑名单、已有宿主订阅和数据库均保留。该操作不使用持久化开关，不会在重启后重复执行。

异常来源可单独还原为默认配置并关闭该来源，其他来源和草稿不变；单来源还原在保存配置后生效。还原失败时提示原因并保留草稿。

备份保存在当前插件实例数据目录的 `config-backups/`。若已在旧版本覆盖并丢失原设置，仍需从升级前备份恢复或手动重新配置。

## 发布范围

当前版本升级为 3.4.2，保留 3.4.0 已撤档说明。数据库结构及宿主最低要求不变，仅维护 v3，不包含主程序或 v2 发布。

# 自动订阅助手 v3.5.0 发布说明

本版本仅面向 MoviePilot v3，以下变化以已发布的 v3.4.2 为基线。

## 市场更新日志

增加：来源级默认订阅规则及规则级订阅设置，支持电影、电视剧和音乐分别配置，规则级优先、来源默认兜底；规则分享与导入保留订阅设置。优化：订阅配置新增默认设置区域，订阅参数支持主程序同款规格预设及站点、下载器、目录和规则组选择，支持自定义填写与选项读取失败重试。

## 默认订阅规则与单条覆盖

各来源的「订阅配置 → 默认设置」提供「默认订阅规则」开关，按电影、电视剧和音乐分别编辑。榜单规则的编辑弹窗另有「订阅规则」开关，用于为当前规则设置独立参数。

新建自动订阅时，以识别后的媒体类型选择设置：先使用通过全部筛选的规则级设置，再使用来源默认规则，最后沿用主程序默认值。同一作品命中多条有效规则时，按排列顺序取第一条启用了对应类型订阅设置的规则。两级设置按媒体类型整体选择，不逐字段混合；已选设置中未填写的字段遵循主程序默认行为。

关闭开关会保留已填内容。清空某个类型并应用后，移除此类型覆盖，恢复上级兜底；应用弹窗后仍需保存插件配置。新设置仅影响后续新建的自动订阅，不修改已有订阅或主程序全局默认规则；历史补充编辑继续使用本次手动设置。

## 参数选择与配置界面

默认设置使用与来源调度、抓取选项一致的独立区块。电影、电视剧和音乐使用各自适用的字段与下拉选项，基础项直接显示，低频选项收进高级设置。

影视质量、分辨率、特效和音乐音质、格式、码率、位深、采样率使用主程序同款预设值。站点、下载器、下载目录和过滤规则组读取当前主程序的实际配置；目录按「名称（路径）」展示，同一路径合并别名，保存时使用真实路径。未配置的选项列表为空，读取失败会提示、支持重试，并保留手动填写能力。

支持普通订阅与洗版，电视剧另有全集洗版，音乐另有最低音频参数。自动触发不包含「订阅时编辑更多规则」，媒体身份、季号、总集数和订阅归属仍由识别与既有管线处理。

## 分享、升级与发布范围

规则分享和导入会保留规则级订阅设置，并按媒体类型与可用字段校验；不分享来源默认设置、调度或通知。已有无订阅设置的分享文件继续使用来源兜底。

从旧版本升级后，两级设置默认关闭，不自动改变原有订阅策略。来源配置升级、异常来源隔离和还原默认配置沿用现有机制，历史与黑名单不变，无新增数据库迁移。宿主最低要求保持不变，仅维护 v3，不包含主程序或 v2 发布。

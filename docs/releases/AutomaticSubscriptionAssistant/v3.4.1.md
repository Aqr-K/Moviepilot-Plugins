# 自动订阅助手 v3.4.1 发布说明

本版本仅面向 MoviePilot v3，修复 3.4.0 遗漏的旧订阅配置自动升级。

## 市场更新日志

修复：旧版本升级后榜单配置未自动迁移的问题，保留原榜单、地区组合、筛选条件、调度及启停设置；迁移前自动备份，异常时保留原配置并停止任务；配置页读取迁移结果，防止保存时覆盖旧设置。

## 升级行为

旧版豆瓣榜单与自定义 RSS、猫眼平台与类型组合、奈飞全球及地区榜、热门媒体和 Mikan 配置自动转换为规则。原有评分、年份、媒体类型、获取数量、调度、启停及共享设置随之保留；热门媒体按旧版每风格获取条数拆分规则，Mikan 保留分别跟随日历的年份与季度。旧音乐榜单选择也按来源转换为规则。

迁移前在插件实例数据目录 `config-backups/` 保存完整原配置；迁移与持久化校验成功后恢复执行。重复启动不重复创建规则。遇到无法等价转换的配置或备份、写入失败时停止自动任务并提示原因，防止扩大订阅范围。

配置页面使用后端迁移结果，不再将旧字段替换为空规则后保存；加载失败时阻止保存。已有新规则（包括用户清空的规则）保持原样。

若已经在 3.4.0 中保存空规则并覆盖原设置，需要从升级前宿主备份恢复或手动重新配置。此次升级无法还原已丢失的数据，也不会推测或重新启用已删除的规则。

数据库结构与历史、黑名单保持当前版本，不涉及新增 SQL 迁移；宿主要求不变。本次不包含主程序发布及 v2 更新。

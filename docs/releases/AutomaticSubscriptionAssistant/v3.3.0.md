# 自动订阅助手 v3.3.0 发布说明

本版本为 MoviePilot v3 正式版，以下变化以已发布的 3.2.0 为基线。

## 市场更新日志

增加：订阅历史支持补充编辑，可修正媒体信息、手动设置订阅参数后重新识别并添加订阅；订阅管理新增原生编辑、搜索、重置、订阅活动和媒体详情入口（需主程序前端支持）。优化：桌面侧栏改为滚动加载，固定顶部统计与操作区，默认进入订阅历史；统一取消订阅文案，适配宿主官方 SDK（需 MoviePilot 3.0.3 及以上）。修复：分页输入框圆角、高度及移动端分页间距、翻页图标对齐问题；奈飞缓存异常时的降级处理。

此段与 `package.v3.json` 的 `history["v3.3.0"]` 一致，也是现有工作流生成 GitHub Release 正文的来源。

## 宿主要求与 SDK 适配

最低宿主版本调整为 **MoviePilot 3.0.3**。插件基类、媒体身份规则、浏览器与订阅只读查询使用官方 SDK；订阅列表读取全部分页，取消订阅和修改状态前通过宿主快照复核归属。官方 SDK 尚未覆盖的订阅写入、媒体库查重和热门统计接口继续沿用原有调用，完整边界见[架构文档](../../../plugins.v3/automaticsubscriptionassistant/docs/architecture.md#宿主-sdk-与兼容边界)。

猫眼 Cookie 获取迁移至官方轻量浏览器接口；该接口不执行旧私有助手的 FlareSolverr 预处理。浏览器不可用时继续降级为无 Cookie 请求，依赖该预处理才能访问猫眼的环境需要确认连通性。奈飞遇到格式异常的持久化缓存时降级为内存缓存，并保留原数据。

## 历史补充编辑

在「订阅历史 → 卡片更多 → 补充编辑」修正媒体名称、类型、年份、来源/ID、目标季及剧集组，再重新识别并尝试新增订阅。特别篇支持 S00。

本次订阅可单独设置搜索关键词、质量、分辨率、特效、站点、下载器、保存路径、搜索间隔、集数范围、洗版模式及过滤规则组。留空使用默认设置，不修改自动任务配置。

显式手动操作可重新添加已取消的订阅，仍执行黑名单、媒体库及已有订阅检查。未识别、未创建或失败时保留输入并显示原因；实际新增成功后关闭弹窗并刷新历史。

## 侧栏与分页

侧栏默认打开订阅历史。桌面侧栏中的历史、订阅管理和黑名单均改为向下滚动加载，隐藏分页和跳页控件；页头、标签、统计与功能区固定，仅列表滚动。手机侧栏及插件详情弹窗继续分页。

修正分页输入框的圆角和高度，使其与原有跳转按钮协调；手机分页按可用宽度展开，前后翻页图标与点击区域居中，并保留两端间距。

## 原生订阅管理与兼容条件

管理卡片可调用主程序的编辑、搜索、暂停/恢复、重置、订阅活动、媒体详情和取消订阅流程，另保留「取消订阅并加入黑名单」。编辑和活动使用原生弹窗，实际保存或操作完成后刷新列表。

**原生管理菜单需要主程序前端提供 `moviepilot:subscriptionManager` 接口。缺少此接口的主程序前端无法启用所有原生菜单，仅升级插件不能补齐该能力。**

旧宿主缺少此接口时，新增原生入口提示升级，原有暂停/恢复和取消订阅保留插件 API 流程。历史补充编辑及侧栏滚动加载不依赖这个新增宿主接口。

本次只维护和发布 MoviePilot v3 插件，v2 保留已发布历史版本。

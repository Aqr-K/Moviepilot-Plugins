# 自动订阅助手 v3.4.0 发布说明

> **已撤档**：此版本缺少旧配置自动迁移，保存配置可能覆盖原设置。GitHub Release 及安装附件已撤下，请升级至 [v3.4.1](v3.4.1.md) 或更高版本。以下保留原发布说明供追溯。

本版本仅面向 MoviePilot v3，以下变化以已发布的 3.3.0 为基线。

## 市场更新日志

增加：AniList 动画榜单，支持趋势、人气、评分、收藏及季度组合；Spotify、苹果音乐、网易云音乐及腾讯音乐榜单，支持单曲/专辑识别与订阅；各来源独立运行通知开关；来源规则分享与导入，支持来源校验及版本校对。优化：各来源统一使用榜单规则弹窗，分别设置筛选条件、启停与获取数量；订阅配置按媒体、音乐分组，全局设置保持首位；苹果音乐支持按规则独立选择地区与榜单；订阅管理显示榜单来源并支持来源筛选；侧栏仅管理员可见，隐藏配置入口及关闭按钮；完善历史与黑名单升级保护，升级前自动备份，异常时保留数据并停止自动任务。修复：插件停止后在途任务仍可能继续添加订阅的问题。

此段与 `package.v3.json` 的 `history["v3.4.0"]` 一致，也是正式发布工作流生成 Release 正文的来源。

## 动画与音乐新来源

新增 AniList 趋势、人气、评分、收藏和年份/季度组合；Spotify 全球歌曲与专辑周榜；Apple Music 热播歌曲和 iTunes 歌曲/专辑榜；网易云 65 个与腾讯音乐 29 个固定榜单（腾讯排除 MV 榜）。音乐通过宿主原生音乐识别和订阅，保存艺术家与实体类型，支持历史、筛选、补充编辑和黑名单。接口与范围见[来源说明](../../../plugins.v3/automaticsubscriptionassistant/docs/sources.md)。

苹果音乐榜单通过统一规则弹窗，逐条选择地区、榜单和获取数量。例如美国 iTunes 专辑、日本 Apple Music 热播歌曲独立监听。

订阅配置侧栏按「全局设置 → 媒体 → 音乐」组织，媒体、音乐使用带文字的分隔线，各来源在分组内按固定顺序排列。

## 独立来源规则

十个来源统一使用榜单规则管理弹窗。每张卡片可命名、启停、编辑与移除，分别设置该来源支持的时间、类型、筛选及数量；网易云/腾讯可按分组搜索榜单。奈飞全球周榜与史上最热可以同时监听，地区周榜也在同一弹窗中设置国家与类型；苹果音乐、猫眼分别按规则选择地区/榜单或平台/网播类型，不再提供矩阵式多元组装。

跨规则命中只订阅一次，历史显示全部命中规则。规则须完整通过自己的条件，避免不同规则的筛选条件串用；部分规则抓取失败保留其它结果并报告错误。全部移除后停止监听。旧平铺来源配置会停止监听，请在新卡片中重新设置并确认条件后保存，避免直接套用默认规则。

## 来源独立通知

「订阅配置 → 对应来源 → 来源与调度」新增「运行通知」。全部十个来源各自保存开关，默认关闭；同一来源下的榜单共用该来源开关。

通知涵盖运行完成、空结果和失败。部分条目已处理后抓取失败时，在一条失败通知内附带处理统计，避免再发送一条成功通知。停用过程中取消的旧任务不发送运行结果，连通性测试也不发送运行通知。全局设置中的通知开关移至来源设置，升级后按需要为各来源开启，不继承旧全局值。

## 订阅来源与侧栏

订阅管理卡片显示创建订阅时记录的榜单来源，筛选面板新增来源多选。只按可追溯的成功历史或成功账本匹配，按媒体来源、类型、季号及剧集组区分；无法追溯的订阅显示未知来源，不凭名称猜测。修剪展示历史后仍保留已登记来源。

侧栏入口仅管理员可见。全页隐藏配置切换与右上角关闭按钮，不恢复上次页签，配置页内的显式切换仅影响当前窗口。统一主入口为 `#/plugin-app/AutomaticSubscriptionAssistant/main`，仪表盘进入链接同步调整。

## 数据升级与停用保护

升级自动接管旧数据库及黑名单。已有 SQL 库需要升级时先保存实例快照；SQLite 使用完整备份协议覆盖 WAL 中已提交的数据。黑名单与历史、成功账本一同纳入插件数据库快照，清理历史不会删除黑名单。

迁移失败时保留源数据并停止自动任务，手动运行和历史重新识别/补充订阅也不会绕过未就绪状态；修复原因并重新加载后重试。版本不匹配或表结构损坏时不静默建空库，也不自动降级。

停止信号到达后，识别、媒体库查重及订阅查重中的旧任务不再继续提交新订阅。最终订阅提交与停止信号串行处理。

逻辑恢复仅供停机维护，校验同一实例和相同数据库结构版本，恢复前再次备份。没有新增在线恢复入口。配置、provider 缓存与宿主真实订阅不属于本插件 SQL 快照范围。管理边界与操作限制见[数据库生命周期](../../../plugins.v3/automaticsubscriptionassistant/docs/database.md)。

## 宿主要求

最低要求仍为 MoviePilot 3.0.3，运行宿主需提供文档列出的公开 SDK、插件数据库句柄及迁移钩子。本轮回归使用当前本地 v3 开发宿主，并不表示已在所有历史宿主版本部署验证。

原生订阅管理菜单仍需主程序前端提供对应宿主入口，完整条件见[架构文档](../../../plugins.v3/automaticsubscriptionassistant/docs/architecture.md#宿主-sdk-与兼容边界)。本次不包含主程序前后端发布，也不更新 v2。

普通 HTTP 局域网访问下，即使浏览器没有提供 `crypto.randomUUID`，也能正常新建规则。管理弹窗「应用」后需保存配置页，规则才会持久化。

## 规则分享与导入

十个来源的规则管理弹窗增加导入与分享图标，清空改为图标按钮，依次位于左下角。可复制/下载 JSON，粘贴或文件导入；内容携带来源、生成插件版本、分享格式版本及字段定义，限定同源使用。

导入前显示版本、规则明细及重复统计，支持追加去重或替换。旧插件规则通过当前校验后可复用，新增可选字段会提示补值；无法保留语义的变更要求先校对。操作只作用于规则草稿，应用后保存配置才持久生效。

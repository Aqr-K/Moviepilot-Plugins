# 自动订阅助手 v3 前端

本目录是自动订阅助手的 Vue 3 联邦前端，后续仅维护、测试和发布 MoviePilot v3 版本。使用方法见[插件说明](../README.md)，后端边界见[架构文档](../docs/architecture.md)。本文说明当前源码的前端实现，包含黑名单、侧栏入口与仪表盘概览。

## 联邦入口

`vite.config.js` 暴露以下组件，构建入口为 `dist/assets/remoteEntry.js`：

| 名称 | 组件 | 用途 |
| --- | --- | --- |
| `Page` | `src/components/Page.vue` | 历史、订阅管理、黑名单的数据页与分页；不恢复旧页签 |
| `Config` | `src/components/Config.vue` | 全局与十类来源配置，可切换到数据页 |
| `Dashboard` | `src/components/Dashboard.vue` | 当前订阅/黑名单/历史指标、来源运行状态、结果分布与最近成功记录 |
| `AppPage` | `src/components/AppPage.vue` | 侧栏通用入口，复用 Page，不指定初始页签 |

后端侧栏名称取 `self.plugin_name`，显示“自动订阅助手”，使用 `mdi-rss` 订阅图标。宿主只为已启用插件聚合入口，权限为 `admin`，仅管理员可见。当前主入口为 `nav_key=main`，地址为 `#/plugin-app/AutomaticSubscriptionAssistant/main`；入口不恢复页签，侧栏页不显示配置切换与右上角关闭按钮。

来源配置在「来源与调度」中提供独立的运行通知开关，保存到 `providers.<id>.notify`；概览展示开启通知的来源数量，不再使用全局通知开关。

## 共用布局

- `PluginTabs.vue`：历史、管理、黑名单、配置导航；侧栏数据页不显示配置切换标签。
- `MediaCard.vue`：横版海报、状态徽标、元数据与“更多”菜单。列表中明确显示剧集季号，特别篇为 S00。
- `FilterPanel.vue`：筛选与添加表单共用的上置标签、紧凑控件与字段间距；支持搜索、年份范围、选择、单值文本和数字。
- `styles/mediaViews.css`：历史与黑名单共用的工具栏、440px 弹窗、卡片网格、加载骨架和空状态。
- `Page.vue`：侧栏在桌面视口（宽度至少 960px）使用连续加载，隐藏分页并固定页头、标签、统计及功能区；详情弹窗和手机侧栏继续分页。`useMediaGrid.ts` 测量列数，分页模式的桌面每页三行，单列使用用户行数设置。
- `ProgressiveList.vue`：以列表自身作为滚动容器，临近底部逐批加载；支持错误重试、末尾提示，并在卸载后清理观察器。
- `BlacklistView.vue`：黑名单筛选、添加与移除；按名称、类型和年份范围筛选，草稿应用后生效。
- `BlacklistDialog.vue`：手动添加、从历史加入、退订并忽略的共用弹窗；只有取消真实订阅时使用危险操作按钮。

黑名单列表从后端读取完整规则，筛选与分页在前端完成；连续加载模式逐批呈现筛选结果。历史列表的筛选、分页与全选身份键查询由后端完成，桌面侧栏按每批 24 条追加并按历史身份去重；筛选或刷新从首批重新开始，失败保留已有卡片并允许重试。批量退订或暂停/恢复须保留失败项供重试，不能把部分成功当作全部成功。

## 历史补充编辑

`SupplementDialog.vue` 复用 `FilterPanel`，修改媒体身份、明确季号（支持 S00）与本次订阅参数，通过 `POST /history/supplement` 提交。站点、下载器和规则组使用宿主认证 API 获取选项，兼容宿主标准 envelope；选项失败可保留默认设置继续操作。

仅实际新建时关闭弹窗；未识别、命中黑名单/已有订阅或失败时保留输入并展示原因。调用期间防重复提交，关闭/重开时丢弃迟到选项，卸载后忽略迟到创建响应。补充编辑使用插件后端处理，不依赖原生管理菜单的新增宿主入口。

## 原生订阅管理

`SubscribeView` 注入 `moviepilot:subscriptionManager`，只向宿主传 `action`、`subscriptionId` 和 `onChanged` 回调。卡片菜单对接原生编辑、搜索、暂停/恢复、重置、订阅活动、媒体详情和取消订阅，不复制宿主编辑表单或活动列表。宿主重新读取订阅并校验当前用户权限；取消确认不刷新，保存/移除或实际变更后刷新列表。

需要主程序前端提供上述宿主入口。旧宿主中编辑、搜索、重置和活动等新入口显示能力缺失提示，暂停/恢复及取消订阅保留原有插件 API 流程。调用期间按卡片阻止重复提交，卸载后的编辑保存回调不再更新列表。

## 仪表盘接入

在主程序仪表盘设置中启用“自动订阅助手”（元信息名称为“自动订阅助手 · 订阅概览”）。`Dashboard.vue` 沿用 `overview` 标识，通过宿主注入的 API 请求 `plugin/AutomaticSubscriptionAssistant/dashboard`，默认 300 秒刷新。

历史数量表示当前保留的展示记录，黑名单数量表示规则条数，插件订阅数量按配置用户名读取并包含暂停项。空历史不会隐藏来源或规则指标；近期成功记录最多五条，标题包含季号与剧集组。底部入口指向该插件的侧栏页面。

刷新采用请求完成后调度，在途去重；`allowRefresh=false`、周期变更和卸载时清理计时器。失败时保留最近成功值并提示错误，卸载后不再接收迟到响应。模板支持宿主边框模式及窄卡片，按钮和提示随宿主语言切换。

## 本地预览

在本目录安装锁定依赖后启动：

```bash
yarn install --frozen-lockfile
yarn dev
```

Vite 开发端口默认 `5001`。`src/App.vue` 是开发壳，可切换宽度、语言和主题；`src/dev/mockApi.ts` 提供内存 API。预览数据随刷新重置，不用于验证宿主鉴权、真实订阅、重启持久化或跨来源识别。

## 真实宿主联调

1. 构建联邦产物：`npm run build`。
2. 将当前源码及 `frontend/dist/assets` 安装到 MoviePilot v3 的运行插件目录，或通过宿主本地插件仓安装/同步。
3. 在插件详情页或侧栏“自动订阅助手”打开页面。启用总开关和至少一个有效来源后，宿主才会显示侧栏入口。
4. 前端使用宿主注入的 `api` 调用 `plugin/AutomaticSubscriptionAssistant/...`，由宿主完成认证和静态资源访问授权。

页面依赖宿主 Vue/Vuetify。构建按现有配置共享这些运行时，且仅在联邦构建时剥离重复的 Vuetify 样式；开发壳保留完整样式。切换本地安装产物后，可强制刷新页面清除旧模块缓存。

## 验证与分发

```bash
npm test
npm run build
```

`tests/regressions.test.mjs` 使用实际组件脚本及 Vue 响应式环境，覆盖历史全选响应顺序、管理部分失败、黑名单提交与重试、筛选草稿、共享分页和特别篇显示，以及仪表盘零历史、刷新失败保留数据、在途去重与计时器清理。这些是组件行为测试，不能替代浏览器联调。

浏览器应检查详情与侧栏入口、添加/筛选弹窗的一致性、桌面与窄屏布局，并在测试后移除临时验证规则，保留用户原有数据。

`dist/` 按仓库规则忽略；Release 工作流在发布时构建并打包产物。本文对应插件 3.4.1。后续只发布 v3。

音乐历史和黑名单支持音乐类型、艺术家及单曲/专辑标签；补充编辑可定义艺术家和音乐实体类型，隐藏影视画质/分辨率控件。新来源复用现有来源与调度区域和独立通知开关。

全部十源统一使用 `rule-list`：主页面通过「配置规则」按钮打开规则管理弹窗，弹窗中添加、编辑、启停和移除卡片；「应用」提交到配置页草稿，「取消」丢弃本次管理改动。原地区/平台矩阵控件及其 schema 已移除。

订阅配置侧栏保持「全局设置」第一位，其后以带文字的分隔线划分「媒体」和「音乐」。媒体依次为豆瓣、猫眼、热门媒体、Mikan、奈飞、AniList；音乐依次为 Spotify、苹果音乐、网易云音乐、腾讯音乐。显示顺序不依赖后端返回顺序；收起侧栏时仅显示分隔线，展开及移动端保留分组文字。分组标题与分隔线共用固定 34px 行高，展开/收起时保留纵向位置；展开侧栏按全部来源中的最长名称计算宽度，并预留滚动条空间，切换选中项不改变列宽。

## 来源规则编辑

`RuleCards.vue` 渲染 `rule-list` 字段：入口只显示数量摘要，管理弹窗展示卡片；子弹窗编辑规则，管理草稿与来源配置分开，取消不写回。`src/utils/rules.js` 负责语义重复判断、有界字段校验及摘要；取消编辑不写回配置。榜单选择支持搜索，网易云/腾讯提供分组过滤。来源 schema 的 `fields/presets/visible_when/options_by` 同时支持字段条件和依赖选项。

`src/dev/providerSpecs.json` 是从后端契约导出的本地预览样本，覆盖全部十源；生产组件仍通过认证 API 读取 schema。`tests/rules.test.mjs` 验证响应式草稿、保存重载、重复/非法条件、类型联动、启停和空列表。历史卡片从 `source_item.source_meta.matches` 展示全部命中规则。

新增规则通过 `createRuleId` 生成配置标识；支持缺少 crypto/randomUUID 的普通 HTTP 环境。新增、编辑和应用流程分别校验条件，防止来源配置已刷新时覆盖新数据。

## 入口状态与构建核对

不再读写 `asa.pageView`，旧存储值不会影响新窗口。配置页中的历史、管理和黑名单切换只影响当前窗口；返回配置时保留未保存草稿，关闭窗口后不继承该目标页签。

规则配置页只显示按钮与数量，新增、搜索、编辑、启停和删除均在管理弹窗内。弹窗沿用原组合管理的 520px 宽度、图标标题、卡片背景及 16px 紧凑开关。

`npm run build` 同时生成 `dist/build-info.json`，包含时间、插件版本、联邦入口与四个组件的文件名及 SHA256。本地安装应整体替换 `frontend/dist`（含 `assets/remoteEntry.js`），再强制刷新页面或重新打开浏览器标签，不能只覆盖单个 Config 文件。插件版本相同的本地构建也可能有不同组件哈希，按 build-info 中的文件名核对实际加载内容。

## 规则分享格式

规则管理底部的图标按钮依次为导入、分享、清空；分享打开 JSON 文本及复制/下载，导入支持粘贴、文件、预览、追加去重或替换。`RuleTransferDialog.vue` 管理交互与异步文件读取，关闭/切换来源/卸载后丢弃迟到结果。`utils/ruleTransfer.js` 拥有来源约束、版本信封、字段语义快照和校验；无网络分享或写入其它用户配置。

`formatVersion=1` 与插件生成版本分开保存。Vite 从插件 `__init__.py` 读取版本，注入 `__ASA_PLUGIN_VERSION__`；来源由配置页显式传入，不能由待导入文件选择目标来源。导入仅生成规则草稿，不提交 API；保存时继续走后端原有校验。旧插件版本会显示差异，语义无法保留的字段拒绝自动转换，可选新增字段补默认值并在预览提示。

`tests/ruleTransfer.test.mjs` 覆盖全部十源往返、异源拦截、旧版校对、格式版本、字段语义变化、数量/大小、重复合并、替换和文件读取生命周期。
